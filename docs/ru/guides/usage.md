# Использование

**[← Назад к оглавлению](../README.md)**

**Документация:** [English](../../en/guides/usage.md) · Русский · [日本語]()

После подключения библиотека не требует специального API для отправки запросов. Используйте обычный `HttpClient`:

```ts
this.http.post('/api/products', product).subscribe();
```

- При наличии интернет-соединения запрос выполняется обычным способом.
- Если соединение отсутствует, запрос автоматически помещается в очередь.

Никакой дополнительной обёртки, отдельного сервиса или ручного управления очередью не требуется — `offlineSyncInterceptor` перехватывает запрос до того, как он уйдёт по сети, и сам решает, как с ним поступить.

## Поддерживаемые методы

Библиотека ставит в очередь только методы, изменяющие данные на сервере:

- `POST`
- `PUT`
- `PATCH`
- `DELETE`

`GET`-запросы никогда не сохраняются в очередь — подробнее в разделе [Ограничения](limitations.md).
