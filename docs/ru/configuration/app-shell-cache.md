# App Shell Cache

**[← Назад к конфигурации](index.md)**

**Документация:** Русский · [English](../../en/configuration/app-shell-cache.md)

`appShellCache` позволяет приложению **открываться без интернета**: Service Worker сохраняет файлы приложения в `Cache Storage` браузера и отдаёт их, когда сети нет.

## Зачем это нужно

Offline queue сохраняет запросы, пока нет сети. Но если пользователь **перезагрузит страницу** без интернета, браузер не сможет скачать сам Angular-приложение — и до очереди дело просто не дойдёт.

App Shell Cache решает эту проблему. *App shell* — это набор файлов, который нужен для запуска приложения:

* HTML;
* JavaScript;
* CSS;
* шрифты;
* изображения и другие поддерживаемые ресурсы.

## Как включить

Передайте `appShellCache.enabled` в `provideOfflineSync()`:

```typescript
provideOfflineSync({
  appShellCache: {
    enabled: true,
  },
})
```

Остальная часть `appConfig` остаётся такой же, как в разделе [Подключение](../README.md#подключение).

## Опции

| Опция     | Тип       | По умолчанию | Описание                                                     |
|-----------|-----------|--------------|--------------------------------------------------------------|
| `enabled` | `boolean` | `false`      | Включает кэширование файлов приложения через Service Worker. |

## Что нужно для работы

Для App Shell Cache необходим файл Service Worker — `ngx-offline-sync-sw.js`, доступный по адресу `/ngx-offline-sync-sw.js`.

Его настраивает `ng add`:

```bash
ng add ngx-offline-sync
```

Команда копирует файл в `src/assets/` и добавляет его в `assets` в `angular.json`. Если вы установили библиотеку через `npm install`, автоматическая настройка не запускалась — выполните `ng add ngx-offline-sync`, чтобы запустить установочную схему.

> Service Worker работает только по **HTTPS** или на **localhost**.

## Как это работает

```text
Application
    ↓
Service Worker
    ↓
Cache Storage
    ↓
HTML / JavaScript / CSS / fonts / images
```

1. Пользователь открывает приложение **с интернетом** — Service Worker сохраняет файлы в `Cache Storage`.
2. Позже страница перезагружается **без интернета**.
3. Service Worker берёт сохранённые файлы из `Cache Storage`, и приложение открывается.

## App Shell Cache и offline queue

Это две независимые возможности, которые хорошо работают вместе:

| Функция         | За что отвечает                                                      |
|-----------------|----------------------------------------------------------------------|
| App Shell Cache | Приложение **открывается** без сети                                  |
| Offline queue   | `POST`, `PUT`, `PATCH`, `DELETE` **отправятся** после появления сети |

## Как проверить

1. Запустите приложение **с интернетом** и дождитесь полной загрузки.
2. Откройте DevTools → **Application** → **Service Workers** и убедитесь, что Service Worker активен.
3. Откройте DevTools → **Network** и включите режим **Offline**.
4. Перезагрузите страницу — приложение должно открыться.

## Частые проблемы

| Проблема                           | Что проверить                                                                                    |
|------------------------------------|--------------------------------------------------------------------------------------------------|
| Приложение не открывается без сети | Открывали ли вы его хотя бы один раз **с интернетом**? Включён ли `appShellCache.enabled: true`? |
| Service Worker не появляется       | Выполнен ли `ng add ngx-offline-sync`? Открывается ли файл `/ngx-offline-sync-sw.js` в браузере? |
| Service Worker не регистрируется   | Приложение запущено по HTTPS или на localhost?                                                   |
