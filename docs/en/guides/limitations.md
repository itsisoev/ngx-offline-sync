# Limitations

**[← Back to overview](../../../README.md)**

**Documentation:** English · [Deutsch](../../de/guides/limitations.md) · [Русский](../../ru/guides/limitations.md)

- The library is designed to sync the following HTTP methods: `POST`, `PUT`, `PATCH`, `DELETE`.
- `GET` requests are not added to the offline queue.
- The queue is stored locally in the browser's IndexedDB.
