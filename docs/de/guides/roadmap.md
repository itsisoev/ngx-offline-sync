# Roadmap

**[← Zur Übersicht](../../../README.md)**

**Dokumentation:** Deutsch · [English](../../en/guides/roadmap.md) · [Русский](../../ru/guides/roadmap.md)

Das Projekt wird aktiv weiterentwickelt. Geplante Verbesserungen umfassen:

- Unterstützung für konfigurierbare Wiederholungsstrategien
- Erweiterte Konfigurationsoptionen für die Warteschlange
- Verwaltung von Anfrageprioritäten
- Die Möglichkeit, Anfragen aus der Warteschlange abzubrechen und zu entfernen
- Erweiterte Verwaltung des Synchronisierungsstatus
- Verbesserte Behandlung von Fehlern und Netzwerkstatus
- Erweiterte Konfigurationsoptionen für IndexedDB
- Zusätzliche Werkzeuge zur Überwachung der Warteschlange
- Erweiterte Testabdeckung
- Verbesserte Dokumentation und Anwendungsbeispiele

Sobald ein wesentlicher Punkt umgesetzt ist, erhält er eine eigene Datei unter [Konfiguration](configuration/index.md) — so wie es derzeit bei [batchSize](configuration/batch-size.md) der Fall ist.
